# JeromeCV 
### Smart CV Builder that adapts to the job

Most CV builders give you 1 boring template. JeromeCV gives you the *right* template for the job.

Applying for Tech? No photo. 
Applying for Cabin Crew? Photo top-left.
Applying for Banking? Professional + Education first.

---

###  Features
- **Job-Specific Templates**: Tech, Cabin Crew, Banking/Corporate to start
- **ATS Friendly**: Clean layouts that pass through HR software
- **Live Preview**: See your CV update as you type
- **1-Click PDF Download**: Powered by html2pdf.js
- **100% Private**: Everything runs in your browser. No data collected.
- **Mobile Friendly**: Build your CV from your phone

###  How to Use
1.  **Pick a Template**: Choose based on the job you're applying for
2.  **Fill Your Info**: Name, Skills, Experience, Education
3.  **Download PDF**: Click "Download PDF" and you're done

### 🛠️ Tech Stack
- HTML5
- CSS3 
- Vanilla JavaScript
- [html2pdf.js](https://github.com/eKoopmans/html2pdf.js) for PDF export
